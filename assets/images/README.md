## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 800x800 pixels for product images
- **Hero Image**: 1200x600 pixels
- **File Size**: Keep under 500KB for optimal loading
- **Style**: Realistic magazine mockups, clean and professional

## How to Add Images

1. Create or obtain magazine mockup images
2. Resize images to recommended dimensions
3. Save with the exact filenames listed above
4. Place in this `assets/images/` folder
5. The website will automatically display these images

## Image Sources

You can create magazine mockups using:
- Canva (free magazine templates)
- Adobe Photoshop
- Figma
- Online mockup generators
